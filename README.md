UIStoppedOnly
=============

自動的に停車時のみUIを表示することを目的とした [TRAIN CREW](https://acty-soft.com/traincrew/) 用の外部ツールです。

走行中 (速度が 0km/h でない) か停車中 (速度が 0km/h である) かが変わったとき、UIの表示/非表示を切り替えます。

## 使用方法

1. TRAIN CREW の「設定 → 操作設定 → 外部デバイス入出力」を「有効」にしする
2. UIStoppedOnly を起動する
3. 乗務を行う
